# 生产部署说明

## 架构

Nginx 提供 `dist` 静态文件，并将 `/api/`、SSE 和鉴权图片请求代理到本机 Uvicorn；MySQL 保存业务数据，`CHAT_STORAGE_DIR` 保存图片二进制文件。

## 构建

```bash
npm ci
VITE_API_BASE_URL=/api/v1 npm run build
```

后端要求 Python 3.11 或更高版本：

```bash
cd backend
python -m venv .venv
.venv/bin/pip install -e .
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## 配置

复制 `backend/.env.example`，至少设置生产数据库 URL、随机 JWT/Fernet 密钥、管理员凭据、实际 CORS 来源和持久化 `CHAT_STORAGE_DIR`。渠道 API Key 只放在服务器环境变量中；不要提交 `.env`、数据库文件或资产目录。

新数据库可执行：

```bash
mysql -u root -p < init.sql
```

## systemd/Nginx 要点

后端应由 systemd 运行并设置 `WorkingDirectory=backend`、`EnvironmentFile=backend/.env`；Nginx 的 API 位置需 `proxy_buffering off` 和足够的 `proxy_read_timeout`，否则流式回复会被缓存。

更新时先记录当前 commit，再 `git pull --ff-only`、重新构建前端、执行 `nginx -t`，最后重启后端。图片资产目录和 MySQL 数据目录必须独立持久化。
