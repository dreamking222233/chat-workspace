# AI 回复展示优化实施方案

- 功能名称：AI 回复展示优化
- 日期：20260903
- 任务级别：中型任务（流式协议清洗、前端消息渲染与交互状态）
- 当前状态：实施完成，最终 Review v5 已通过

## 1. 用户原始需求

优化聊天页的 AI 回复效果，参考 ChatGPT 官网：联网搜索时展示可读的“正在搜索”状态，不显示渠道内部 `search(...)slow|...|1` 协议文本；AI 最终回复按 Markdown 正确渲染标题、粗体、列表、链接等格式。

## 2. 技术方案

1. 基于真实官网版渠道 SSE 样本定义搜索指令语法，兼容 `|QUERY|INDEX` 与 `|QUERY` 两种实际格式，并支持指令在任意 chunk 边界被分割。
2. 在服务端流处理中截获搜索指令，转换为 `search.started` SSE 事件，并仅持久化清洗后的 AI 正文。
3. 前端接收搜索事件，在首个正文 Token 前展示带图标的“正在搜索…”状态；正文开始后自动收起。
4. 使用 `react-markdown` 与 `remark-gfm` 安全渲染 AI Markdown，不注入原始 HTML；补充标题、段落、列表、引用、代码、表格和链接样式。
5. 服务端根据消息关联的 `ModelRequest -> ModelChannel` 判断来源，仅对官网版渠道的历史消息做兼容清洗，显示、复制和导出均不暴露内部协议，Codex 渠道的同形普通正文保持原样。
6. 增加解析器单元测试、API 流/持久化测试和前端渲染测试，再执行全量测试、生产构建及真实页面验证。
