# 聊天思考等级实施方案

- 功能名称：聊天思考等级
- 日期：20260902
- 任务级别：中型任务（聊天交互、请求契约、Provider 传输及测试）
- 当前状态：实施完成，二次 Review 通过

## 1. 用户原始需求

聊天页面的思考按钮支持选择低、中、高、超高四种思考等级；渠道1官网版和渠道2 Codex GPT 均应支持并传递相应等级。

## 2. 技术方案

1. 将布尔 `thinking` 状态改为 `reasoningEffort`，可选值为空、`low`、`medium`、`high`、`xhigh`。
2. 点击思考按钮展开等级菜单；选择后按钮显示当前等级，再次选择“关闭思考”清空参数。
3. 文本发送和重新生成请求统一携带所选 `reasoning_effort`；图片模式不使用该参数。
4. 后端请求 Schema 对等级做枚举校验，Provider 适配器继续按 OpenAI Chat Completions 的 `reasoning_effort` 或 Responses 的 `reasoning.effort` 传递，因此两类渠道共用一致链路。
5. 增加前端交互/请求测试及后端参数传输测试，并对两个真实渠道做协议调用验证。
