## 已实现行为

- 管理员可通过 `/api/v1/admin/model-channels` 创建、编辑、启停、删除渠道。
- 渠道字段包含 OpenAI 协议、Base URL、API Key、文本/图片/双模态、模型列表和优先级。
- 列表接口只返回 API Key 掩码；空模型列表、无效 URL、重复名称会被拒绝。
- 前端支持筛选、创建/编辑弹窗、启停开关、配置测试和删除确认。
- 用户端入口为 `/`、`/login`、`/register`、`/chat`；管理端入口为 `/admin/model-channels`、`/admin/users`、`/admin/usage`。
- 管理端使用独立侧边栏和顶部布局；前端按身份角色拦截，后端 API 继续执行管理员角色校验。
- 用户数据默认写入本地 MySQL `chat_workspace`；模型渠道 API Key 使用 Fernet 加密存储，列表只返回掩码。
- 文本聊天优先调用启用渠道；无渠道时使用本地演示流，权限拒绝不会回退演示回复。
- 图片请求调用 OpenAI `/images/generations`，生成资产按用户隔离保存。
- 项目页支持创建项目和项目内新建会话；聊天更多菜单支持 Markdown/JSON 导出。
- 管理端用户页支持搜索、状态、详情和按月授权；用量页展示请求、模态、状态、token 和延迟。
- 未启动后端时前端保留演示渠道，页面仍可预览和操作。

## 收尾修复与验证

- 将文本 SSE 的模型请求和 assistant 更新迁移到生成器自己的 `SessionLocal` 会话，避免 FastAPI 请求依赖提前释放造成正文为空、状态一直为 `running`。
- 抽取 `_resume_stream` 和 `_start_text_stream`，普通发送与重新生成共用事件、幂等和重放逻辑；重新生成复用目标文本 assistant 消息，不新增重复用户消息。
- 指定模型找不到启用渠道时返回 503；未指定模型且没有配置渠道时仍保留 `local-demo` 开发演示路径。图片请求错误包含指定模型信息，重新生成也受模型限流限制。
- 更新项目归档后的会话关联校验；用户端启动时读取归档会话，HTTP 模型错误会清理乐观消息，项目内新会话立即刷新计数。
- token 读取兼容 OpenAI Chat Completions 的 `prompt_tokens`/`completion_tokens` 及部分兼容供应商的 `input_tokens`/`output_tokens`。

## 已知限制与可选增强

- 真实供应商请求需要管理员在模型渠道页面配置可用 OpenAI-compatible Base URL 和 API Key；无渠道时文本使用本地演示流。
- 图片请求已实现 OpenAI 协议适配，但需要图片渠道和真实供应商才能生成图片。
- 当前导出直接返回下载响应；对象存储短期链接、Playwright 像素级视觉回归和结构化日志可作为生产增强。
