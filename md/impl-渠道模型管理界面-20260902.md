## 1. 实现内容

- 渠道行新增“管理模型”入口和模型管理弹窗。
- 打开弹窗时通过只读管理 API 读取该渠道的 `/v1/models`，展示最新远端模型；打开和取消不会改变已启用集合。
- 每个模型展示文本/图片能力和勾选状态，可选择要在用户端展示的模型。
- 保存时调用渠道 PATCH 更新模型数组，模型 ID 不再需要复制到逗号分隔输入框。
- 同步、保存、取消、空列表和错误状态均有明确反馈；已有 60 秒自动同步逻辑保持不变。
