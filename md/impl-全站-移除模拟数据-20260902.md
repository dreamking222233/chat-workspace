## 3. 核心接口行为

| 场景 | 结果 |
|---|---|
| 无可用文本渠道发送/重新生成 | HTTP 503，消息、请求记录和会话字段不变 |
| 显式渠道不存在、停用或能力不匹配 | HTTP 422 |
| 会话/项目/归档/模型/授权加载失败 | 对应错误和重试，不填充模拟数据 |
| 用户/用量加载失败 | 隐藏统计与列表，显示错误和重试 |
| 停止接口失败或 `stopped=false` | 保持当前请求状态，不显示“已停止” |
| 图片会话切回文本自动模式 | 不提交图片模型，由服务端解析真实文本渠道 |
