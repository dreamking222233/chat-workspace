## 1. 实现内容

- 管理端渠道表单已移除模型列表输入框，改为说明：保存后自动请求 `/v1/models`。
- 新建渠道允许模型列表为空，保存基础配置后自动调用本站同步接口；编辑保存同样触发同步并刷新持久化渠道。
- 同步仍由后端请求渠道 Base URL 下的 `/v1/models`，成功时完全替换模型列表，失败时保留旧模型列表并记录错误。
- 每个远端模型按照模型 ID 判断能力：名称包含 `image` 为 `image`，其他为 `text`；已有显式能力映射继续保留。
- 用户模型选择器显示渠道类型和模型来源。
