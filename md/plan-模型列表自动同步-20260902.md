# 模型列表自动同步实施方案

- 功能名称：模型列表自动同步

- 任务级别：中型任务（管理表单、渠道 API 校验、同步流程及回归测试）
- 当前状态：实施完成，Review 通过

## 1. 用户原始需求

编辑模型渠道时不再手动填写模型列表；保存渠道后调用该渠道的 `/v1/models` 获取模型。模型 ID 中包含 `image` 的归类为图片模型，其他模型归类为文本模型。

## 2. 技术方案

1. 管理端移除模型列表文本输入，新增模型自动同步说明。
2. 新建渠道先保存基础配置，再调用本站 `/admin/model-channels/{id}/sync-models`；编辑渠道保存后同样同步，模型列表只以远端结果为准。
3. 后端允许新建时模型列表为空，避免伪造模型；同步接口从 `/v1/models` 读取并按模型名 `image` 关键字生成 `capabilities`，其余模型标记 `text`。
4. 保留已有能力映射覆盖，但模型列表完全替换为远端结果；同步失败时保留旧列表并给出错误状态。
5. 增加前端和后端测试，验证不发送手工模型、保存后触发同步及图片/文本分类。
