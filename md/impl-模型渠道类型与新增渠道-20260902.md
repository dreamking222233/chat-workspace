## 3. 协议验证

- `GET http://provider.example:8080/v1/models`：HTTP 200，返回 13 个模型。
- 管理端渠道测试：HTTP 200，`/v1/models` 连接成功。
- `POST /v1/chat/completions`，模型 `gpt-5.4-mini`，流式返回 HTTP 200，收到“渠道2文本测试成功”。
- `POST /v1/images/generations`，模型 `gpt-image-1`、`gpt-image-1.5`、`gpt-image-2` 均返回 HTTP 403，服务端提示当前 API Key 所属分组未开启图片生成权限；请求路径、鉴权及 OpenAI 参数结构均已实际到达渠道。

图片权限开通后，管理页自动同步会保留上述图片模型，聊天图片模式即可沿用现有 OpenAI 图片适配器调用。
